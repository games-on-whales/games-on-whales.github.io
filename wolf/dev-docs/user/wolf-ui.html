Wolf UI

Wolf UI is an application launcher and profile manager. It provides an intuitive interface for organizing, downloading and updating applications and set up cooperative lobbies.

User Interface Overview

Wolf UI consists of two main screens:

  1. Profile Selection Screen: Choose which user profile to access

Profiles can be protected by a PIN to prevent unauthorized access, see configuration/profiles

  1. Application Selection Screen: Browse and launch applications for the selected profile

Greyed out applications aren’t currently installed, you can download them directly from Wolf UI. This will actually pull the Docker images from our open source registry.

Lobbies

When launching an app, you can create a lobby so that multiple users will be able to connect to the same instance. When you do that, Wolf UI will show a lobby in the first page below the profile selection screen.

Return to Wolf UI Hotkey

When you are running an application, you can instantly return to Wolf UI by:

  • pressing Ctrl+ALT+SHIFT+W on your keyboard

  • pressing START+UP+RB on a joypad
